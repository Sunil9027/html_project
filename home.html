What is HTML?

HTML
  • HTML stands for Hypertext Markup Language.
  • HTML is very useful markup language which is used by every web application to make Structure of the web applications.
  • It is very popular markup language which is developed by Tim Berner's Lee in 1991.
  • The purpose to make this language is to share Research Paper on internet to easily everyone see and read.
  • This becomes the base language of every web page that create the skelaton or structure of webpage.
Advantages :
  • This is free and open source markup laguage which means everyone can use wihtout paying money.
  • HTML is simple and easy to understand and learn to build web pages.
  • HTML is case in-sensitive which means you can write tags in uppercase as well as lowecase.
  • HTML is tag-based markup language, every tag has own meaning.
  • HTML is platform independent which means this is run on different web browsers.
  • Now HTML version is HTML5 which provide many additional tag to add audio, video on your websites.
Disadvantages :
  • It is not programming language which means you can't appicable to write logic operations.
  • It not provide good UI (User Interface).
  • We can't run html outside the browser
  • This is not provide functinality to webapplications.
